# Atividade CRUD Notas Frontend

Front-end que consome as rotas CRUD da API Express para gerenciamento de notas da Aula 05.

## Deploy

**[Acessar frontend](https://atividade-crud-frontend.vercel.app)**

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- Fetch API

## Funcionalidades

- Listar todas as notas (`GET /api/notas`)
- Criar nova nota (`POST /api/notas`)
- Atualizar nota (`PUT /api/notas/:id`)
- Deletar nota (`DELETE /api/notas/:id`)
- Estados: carregando, sucesso e erro

## API de referência

[atividade-crud-api](https://github.com/jenifferCamar/atividade-crud-api) — API CRUD de notas no Render.

## Executar localmente

Como não utiliza framework, abra `index.html` diretamente no navegador. O front-end consome a API no Render por padrão.
